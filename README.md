# Website SEO Automation

This repository contains the shared SEO regression checker used by the website repositories owned by `karefined-eng`.

The engine is intentionally dependency-free. Each website repository keeps a small `seo.config.json`, while its GitHub Actions workflow calls `.github/workflows/seo-audit-reusable.yml` from this repository. The checker validates titles, meta descriptions, canonical URLs, Open Graph tags where required, robots sitemap declarations, sitemap XML, route coverage, and intentional exclusions.

The engine reports failures in pull requests instead of silently editing production. This makes canonical and sitemap changes reviewable before the hosting provider deploys them.

## Caller configuration

A static HTML repository can configure individual source files and public URL routes:

```json
{
  "siteUrl": "https://example.com",
  "framework": "static",
  "htmlRoot": ".",
  "routes": ["/", "/about.html"],
  "excludedRoutes": ["/admin.html"],
  "robotsPath": "robots.txt",
  "sitemapPath": "sitemap.xml",
  "requireOpenGraph": true
}
```

A repository whose metadata is generated by a framework can use `framework: source` and list source checks instead of pretending that source files are the final rendered HTML.

## Required sharing setting

If this repository is private and a public website repository calls its reusable workflow, GitHub may require repository Actions access to be enabled for the intended caller repositories. The workflow is read-only and contains no deployment secrets.
